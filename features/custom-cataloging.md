# Custom Cataloging Fields

Define your own metadata schema with **custom cataloging fields**.

## Field types

- Text, Textarea
- Select, Multi-Select
- Date, Numeric
- Taxonomy Tree

![Custom Cataloging Screenshot]({{ site.baseurl }}/assets/images/features/custom-cataloging.png)

## How to add fields

1. Go to the collection's **Meta Fields** page.
2. Click **Add Field**.
3. Choose the type and configure options.
