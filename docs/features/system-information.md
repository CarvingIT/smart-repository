# Sytem Information

The **System Information** page gives administrators a centralized view of the Smart Repository installation and its underlying infrastructure. It consolidates important configuration and health information in a single place, making it easier to verify that the system is correctly installed, configured, and operating as expected.

The page displays the status of essential directory permissions, ensuring that Smart Repository has the required access to store documents, generate thumbnails, create temporary files, and perform other background operations. It also lists installed system dependencies and their versions, including components such as Elasticsearch, OCR libraries, image processing tools, SMTP configuration, and the database. This enables administrators to quickly verify compatibility, identify missing or outdated components, and troubleshoot configuration issues.

In addition, the page provides detailed information about local disk usage, helping administrators monitor available storage space and plan capacity before storage constraints affect document ingestion or system performance.

By bringing together configuration details, software versions, dependency status, and storage metrics, the **System Information** page serves as a valuable diagnostic and maintenance tool. It simplifies system audits, accelerates troubleshooting, and helps ensure that Smart Repository remains healthy, secure, and ready for production use.
