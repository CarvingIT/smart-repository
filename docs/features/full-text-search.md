# Full-Text Search

Smart Repository provides lightning-fast full-text search powered by **Elasticsearch**.

## How it works

1. Documents are automatically indexed when uploaded.
2. Users can search across titles, content, and metadata in milliseconds.
3. Advanced operators like fuzzy search, phrase match, and boolean queries are supported.

![Full-Text Search Screenshot]({{ site.baseurl }}/assets/images/features/SR-full-text-n-fuzzy-search.png)

## Benefits

- Find any document instantly, even among thousands.
- Search inside PDFs, Word documents, and scanned images (with OCR).
- Filter results by cataloging fields, date ranges, and more.
