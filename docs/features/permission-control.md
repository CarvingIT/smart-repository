# Permission Control

Smart Repository offers **fine-grained permission control** so you can decide exactly who sees what.

## Key capabilities

| Role | Permissions |
|------|-------------|
| Viewer | Read-only access to documents |
| Contributor | Upload and edit own documents |
| Maintainer | Manage collection settings and users |
| Admin | Full control over the system |

![Permission Control Screenshot]({{ site.baseurl }}/assets/images/features/permission-control.png)

## How to configure

1. Navigate to the collection settings.
2. Click **Manage Users**.
3. Assign roles to individual users or groups.
