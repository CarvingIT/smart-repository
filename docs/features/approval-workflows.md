# Approval workflows

![Approvals with checklist]({{ site.baseurl }}/assets/images/features/SR-approval-workflows.png)

- Documents can require approval before becoming public.
- Reviewers receive notifications and can approve/reject inline.
- Checklists can be defined in order not to miss important checks at every approval stage, ensuring compliance.
