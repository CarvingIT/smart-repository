# Storage Options

Store documents on configurable storage options.

## Supported providers

- Cloud based S3 compatible storage 
- Google Drive
- Local disk
- NFS share  
- FTP/SFTP

![Cloud Storage Screenshot]({{ site.baseurl }}/assets/images/features/SR-storage-options.png)

Each collection can potentially be mapped to a different storage drive. This provides flexibility.
