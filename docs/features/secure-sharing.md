# Secure Document Sharing with Expiring Protected Links

Sharing documents outside your organization should be simple without compromising security. Smart Repository makes this possible through protected document sharing links.

Instead of emailing large files or creating duplicate copies, users can generate a secure link to a document stored in Smart Repository. The recipient can access the document through the shared link without requiring direct access to the entire repository.

To enhance security and maintain control, each shared link can be configured with an optional expiration date. Once the specified date is reached, the link automatically becomes invalid, ensuring that temporary access does not become permanent.

## Key Benefits
* Secure external collaboration with customers, partners, auditors, vendors, and consultants.
* Time-bound access that automatically expires, reducing the risk of unauthorized future access.
* No duplicate files, ensuring everyone views the latest version stored in the repository.
* Reduced administrative effort, eliminating the need to manually revoke temporary access.
* Improved compliance by limiting document availability to an approved time window.
* Controlled distribution, allowing organizations to share only the intended document instead of exposing broader repository access.

## Common Use Cases
* Sharing contracts with clients for review.
* Providing project documents to external consultants.
* Giving auditors temporary access during compliance audits.
* Sharing engineering drawings or technical manuals with vendors.
* Distributing reports to stakeholders for a limited period.
* Providing students, researchers, or collaborators access to selected learning materials.

With protected, expiring links, Smart Repository enables organizations to collaborate confidently while retaining complete control over who can access documents and for how long.

This feature becomes especially valuable for organizations that frequently exchange sensitive information with external parties, combining the convenience of cloud-based sharing with the governance and security expected from an enterprise document management platform.
