# Localization & Transliteration

Smart Repository supports **multiple languages** and offers transliteration in the search box.

## Capabilities

- Interface available in several languages.
- Type in one script and transliterate to another (e.g., English → Devanagari).
- Locale-aware date and number formatting.

![Localization Screenshot]({{ site.baseurl }}/assets/images/features/localization.png)

## Configuration

Set your preferred locale in `.env` or collection settings.
