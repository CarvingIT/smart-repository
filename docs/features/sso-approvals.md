# Single Sign-On & Approvals

Integrate with your organization's identity provider and control document publishing.

## Single Sign-On

- SAML 2.0 integration.
- Login with Azure AD, Okta, Google Workspace, etc.

## Approval Workflow

- Documents can require approval before becoming public.
- Reviewers receive notifications and can approve/reject inline.
